# Release Notes - v3.4.0

**Release Date:** March 15, 2026

## 🎯 Overview

Version 3.4.0 brings major enhancements to the visual experience with **dynamic sky and celestial animations**, alongside significant feature additions including **enriched Prophet stories**, **smart Hijri calendar offsets**, **sticky Surah headers**, and improved **streak tracking**. This release also includes crucial performance optimizations and UI/UX refinements across the application.

---

## ✨ New Features

### Animated Sky & Celestial Bodies Elements
- **Dynamic Backgrounds**: Added a continuous time-based sky gradient background that smoothly transitions based on the time of day.
- **Prayer Times Enhancements**: Enhanced celestial calculations with dynamic prayer times, incorporating an animated gradient background specifically for the prayer times view.
- **Atmospheric Animations**: Added animated celestial bodies, drifting clouds, meteorites, and birds to the sky layer for a more immersive experience. 

### Hijri Calendar & Date Management
- **Smart Offset Setting**: Introduced a configurable Hijri offset setting with a smart timezone-based default, allowing users to adjust the Islamic date accurately according to their region.
- **Redesigned Calendar**: Completely revamped the calendar component with updated styling, improved navigation, and clear highlighting of today's date.

### Enriched Prophet Stories
- **Interactive Narrative**: Prophet stories within the `journey` module have been deeply enriched with detailed, emotional prose.
- **Meaningful Choices**: Added interactive choices with feedback mechanisms to make the reading experience more engaging.

### Sticky Surah Header
- **Seamless Reading**: Implemented a sticky Surah header in the `juz-ayah` views. The header now remains fixed below the toolbar while scrolling, providing constant context of the current Surah being read.

### Enhanced Streak Tracking & Library
- **Auth-Gated Page Tracking**: The system now tracks the *last read page* in Library PDFs for authenticated users, allowing seamless continuation of reading sessions directly from the streak dashboard. 

### PWA & Dark Mode Improvements
- **Dynamic Icons**: Brought support for dynamic PWA app icons that adapt to dark mode seamlessly.
- **Solid Icon Backgrounds**: Used solid backgrounds (white for light mode, slate-900 for dark mode) to ensure perfect visibility of icons across themes.

### UI/UX & Layout Enhancements
- **Chatbot Refactor**: Implemented dynamic header visibility and refactored the chatbot layout to feature a floating input field and an independently scrollable message area.
- **Zakat Calculator**: Enhanced the layout for the Zakat Calculator and Contribution Tracker, improving usability.
- **Recommended Apps**: Updated the recommended apps widget to feature "Library" and "Zakat" prominently. Renamed the "Search" game to "Words" and assigned it an updated icon. Added "Ilm Quest" section.

---

## ⚡ Performance

### Core Optimizations
- **Islamic Event Lookups**: Optimized the Islamic event lookup algorithms to significantly improve performance, reducing lag during calendar interactions.
- Added strict performance budgets where needed to accommodate new styling expansions smoothly.

---

## 🐛 Bug Fixes

- **Memory Leak**: Fixed a critical subscription memory leak within the `PrayerTimesComponent`.
- **Display Toggles**: Swapped title and subtitle assignments for the Juz tracking display to ensure correct information rendering.
- **Animation Glitches**: Corrected the scale property in the shooting star keyframes animation to prevent visual artifacts.
