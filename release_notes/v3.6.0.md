# Taqwa Tracker v3.6.0 Release Notes

Welcome to **Taqwa Tracker v3.6.0**! This release brings a massive overhaul to the UI and UX with our new Glassmorphism design system, alongside significant improvements to the Quran, Library, and internal architecture.

Here is a summary of all the exciting changes since `v3.5.0`.

## 🎨 Major UI/UX Overhaul
- **Glassmorphism Design:** Replaced flat cards across the app with an elegant `.glass-panel` translucent aesthetic, complete with smooth hover animations and soft shadows.
- **Adaptive Navigation:** Completely rebuilt the global navigation. The desktop view now features a properly aligned sidebar, while the mobile bottom nav intelligently centers the prominent "Home" action button.
- **Responsive Grids:** Migrated the long vertical lists in the **Surah List**, **Juz List**, and **Hadith Chapters** to fully responsive Bento-style CSS grids, drastically improving readability on tablets and desktops.
- **Calendar & Tool Polish:** Refined the Calendar layout, date grids, and modal popups. Adjusted light-theme color palettes app-wide to ensure strict compliance with WCAG AA accessibility contrast standards.

## ✨ New Features & Enhancements
- **Quran Transliteration:** Added full transliteration support to the Quran model and Ayah cards, including the ability to easily copy transliterated text.
- **Translation Popups:** Refined interactions and dark mode compatibility for the Quran translation popup (PR #149).
- **Streak Management:** Introduced a confirmation dialog to prevent accidental resets of your reading streak.
- **Library Persistence:** Enhanced the Islamic Library to better persist your reading state and manage local storage updates efficiently.
- **Data Fetching Optimization:** Optimized Hadith batch fetching and significantly improved bookmark lookup performance.

## 🐛 Bug Fixes
- **Mobile Search:** Fixed frustrating scrolling and clipping issues inside the global search overlays on mobile devices (PR #148).
- **PDF Viewer:** Resolved a bug to ensure valid page numbers are always parsed and loaded correctly when opening books in the Islamic Library.
- **Date Handling:** Refactored date parsing and handling logic within the `ReadStreakService` and `StreakDashboardComponent` to prevent edge-case streak resets.

## 🛠️ Infrastructure & Developer Tooling
- **Angular 21.2.x:** Upgraded core Angular dependencies and the Angular CLI to version `21.2.19`.
- **Bundle Budgets:** Adjusted Angular bundle and component style budget thresholds to accommodate the new UI design system.
- **Agent Context:** Added comprehensive `AGENTS.md` context documentation and introduced new AI agent skills (`agent-browser`, `frontend-design`, etc.) to streamline future development.
