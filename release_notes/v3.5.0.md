# Release Notes - v3.5.0

We are excited to announce the release of **v3.5.0** for Taqwa Tracker! This major update introduces powerful semantic search capabilities, significant performance optimizations, and enhanced financial tools for Zakat calculation.

## 🚀 Key Features

### 🔍 AI-Powered Semantic Search
- **Quran & Hadith Search**: Integrated real-time semantic search across both Quran and Hadith modules.
- **Modular Architecture**: Extracted search logic into reusable, standalone components for better maintainability.
- **Optimized UI**: Updated the search interface with a sleek Emerald design theme and intuitive floating action buttons.
- **Descriptive Results**: Hadith search results now include Chapter numbers, names, and specific Hadith identifiers.

### 💰 Enhanced Zakat Calculator
- **Dynamic Nisab Calculation**: Integrated live silver market rates for real-time Nisab threshold calculation.
- **Smart Caching**: Implemented 24-hour caching for silver rates to ensure high performance while staying up-to-date.
- **Contribution History Reset**: Added the ability to reset Zakat contribution history with a secure confirmation popup.

### 🎨 Design & Experience
- **IndoPak Font Migration**: Migrated the IndoPak Arabic font to a local asset for faster loading times and improved privacy/CSP compliance.
- **Smart Authentication UI**: Conditionally render chatbot and login buttons based on the user's current authentication state.
- **User Confirmation**: Added confirmation popups for critical actions like calculator resets and contribution history clears.

## ⚡ Performance Optimizations
- **Bookmark Lookups**: Significantly optimized bookmark filtering and surah lookups in the BookmarkListComponent.
- **API Efficiency**: Removed redundant API calls during Hadith bookmark removal.
- **Signal-Driven State**: Refactored core modules to utilize Angular Signals and `toObservable` for smoother, more efficient state management.

## 🛠️ Internal Improvements
- **Security**: Updated Content Security Policy (CSP) to align with local font assets.
- **Refactoring**: Modularized the search codebase into independent components.
- **Dependencies**: Bumped project version and updated `package-lock.json` dependencies.
