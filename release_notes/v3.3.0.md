# Release Notes - v3.3.0

**Release Date:** February 22, 2026

## 🎯 Overview

Version 3.3.0 delivers a **security-hardened authentication layer**, a **redesigned Quran reading experience**, **Library PDF reading streak tracking**, and **refreshed dark mode styling**. This release consolidates fixes and features from interim versions v3.2.1 through v3.2.4 into a single major update.

---

## ✨ New Features

### Library PDF Reading Streaks

Users who read PDFs from the **Islamic Library** now have their reading activity tracked in the existing streak system alongside Quran and Hadith reads.

- **Automatic Tracking**: Opening any Library PDF increments the reading streak
- **Continue Reading**: Library items appear in the "Continue Reading" section on the Home page with a 📄 icon
- **Deep Links**: Clicking a library item from the streak dashboard navigates back to the exact PDF
- **Smart Titles**: PDF filenames are automatically formatted into readable titles

### Custom Ayah Dropdown & Toolbar Redesign

- **Segmented Pill Toggle**: Replaced the legacy translation toggle with a modern pill-style UI in both Juz and Surah ayah views
- **Custom Dropdown**: New styled dropdown component replaces the native browser `<select>` for translation selection
- **Arabic Text Labels**: Dropdown options now display Arabic text alongside English names

### Reusable Popup Component

- New shared popup component for consistent modal dialogs across the application

---

## 🔒 Security

### Authentication Credentials Protection (v0.9.2)

- **Moved credentials from URL params to request body** — Passwords and tokens are no longer exposed in URL query parameters, browser history, or server logs
- Applies to login, registration, password reset, and token refresh flows

### Concurrent Token Refresh Fix

- **Resolved race condition** causing premature logout when multiple API calls triggered simultaneous token refreshes
- Fixed invalid payload errors during token refresh operations
- Ensured only one refresh request is made at a time with queued retry

---

## ⚡ Performance

### Prayer Times Widget Optimization

- Pre-computed CSS classes for prayer time status indicators
- Reduced unnecessary recalculations during change detection cycles

## 🎨 UI/UX Improvements

## 📝 Migration Notes

### For Users

No migration needed — this is a frontend-only update. Your reading streak data is preserved.

### For Developers

1. **Frontend Update**: Deploy web version v3.3.0
2. **Backend Update**: Recommended to deploy API v0.9.2 for credential security
3. **Existing Data**: All localStorage streak data is backward compatible — the new `'library'` type is additive
