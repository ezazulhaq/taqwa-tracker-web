# Release Notes - v3.2.0

**Release Date:** February 16, 2026

## 🎯 Overview

Version 3.2.0 introduces the **Frontend Contribution Reversal System** for the Zakat Calculator, providing users with a comprehensive UI to reverse mistaken contributions while maintaining complete audit visibility. This release works in tandem with the backend API v0.9.1 to deliver a seamless contribution correction experience.

---

## ✨ New Features

### Contribution Reversal UI

- **Reverse Button**: One-click reversal for active contributions with confirmation dialog
- **Visual Status Indicators**: Color-coded badges showing contribution status:
  - 🟢 **ACTIVE** - Regular, unreversed contributions
  - ⚪ **REVERSED** - Contributions that have been reversed (struck-through appearance)
  - 🔴 **REVERSAL** - Correction/reversal entries (negative amounts)
- **Enhanced Table Layout**: New Type and Actions columns for better data organization
- **Smart Display**: Amount column shows `+` for contributions, `-` for reversals with appropriate coloring
- **Loading States**: Reversal operations show "Reversing..." state to prevent double-clicks
- **Backward Compatibility**: Works with both old (v0.9.0) and new (v0.9.1) backend APIs

---

## 🔧 Technical Changes

### TypeScript Models

**Updated:** `calculator.model.ts`
- Added `ContributionType` type: `'contribution' | 'reversal'`
- Enhanced `ZakatContribution` interface with optional reversal fields:
  - `contribution_type?`: Type of entry (optional for backward compatibility)
  - `reversed_contribution_id?`: Link to original contribution
  - `is_reversed?`: Flag indicating reversal status

### Services

**Enhanced:** `zakat.service.ts`
- **NEW Method**: `reverseContribution(contributionId, notes?)`
  - Calls backend reversal API endpoint
  - Automatically reloads contributions and summary on success
  - Returns Observable<boolean> for status tracking
  - Includes error handling with console logging

### Components

**Enhanced:** `contribution-tracker.component.ts`
- Added `reversingId` signal to track loading state
- **NEW Method**: `reverseContribution(contributionId, amount, date)`
  - Displays user confirmation dialog with formatted details
  - Handles reversal API calls with loading state management
  - Shows error alerts if reversal fails
- **NEW Method**: `isReversing(contributionId)` - Helper to check loading state

**Updated:** `contribution-tracker.component.html`

Table Enhancements:
- Added **Type** column displaying status badges
- Added **Actions** column with conditional "Reverse" button
- Amount formatting with `+` (green) for contributions, `-` (red) for reversals
- Conditional rendering based on `contribution_type` field presence
- Backward-compatible: hides reversal features when old API is used

Row Styling:
- `reversed-row` class: Striped background pattern with reduced opacity
- `reversal-row` class: Red left border indicator
- Dark mode support for all visual states

**Updated:** `contribution-tracker.component.css`
- Updated grid layout to 5 columns: `120px 150px 100px 1fr 120px`
- Styling for Type column with center alignment
- Styling for Actions column with center alignment
- Striped background pattern for reversed entries
- Red border accent for reversal entries
- Responsive mobile layout with inline labels for all columns
- Full dark mode compatibility

## 🎨 User Experience

### Reversal Workflow

1. **Navigate** to Contribution Tracker page
2. **View** contribution history with status badges
3. **Click** "Reverse" button on any active contribution
4. **Confirm** reversal in dialog showing:
   ```
   Are you sure you want to reverse this contribution?
   
   Amount: $500.00
   Date: Feb 15, 2026
   
   This will create an offsetting entry and cannot be undone.
   ```
5. **Result**:
   - Original contribution marked as REVERSED (grayed/striped)
   - New REVERSAL entry created with negative amount
   - Summary updated to show net contributions
   - Both entries remain in history for audit trail

### Visual Indicators

| Status | Badge Color | Amount Color | Special Styling | Action Available |
|--------|-------------|--------------|-----------------|------------------|
| ACTIVE | Green | Green (+) | None | ✅ Reverse |
| REVERSED | Gray | Green (+) | Striped background | ❌ None |
| REVERSAL | Red | Red (-) | Red left border | ❌ None |

## 🔄 Backward Compatibility

This release is **fully backward compatible** with backend API v0.9.0:

- Reversal fields (`contribution_type`, `is_reversed`, `reversed_contribution_id`) are **optional**
- If backend doesn't provide these fields:
  - Reversal features are automatically hidden
  - Type column shows all contributions as "ACTIVE"
  - Actions column shows "—" (no actions available)
- Works seamlessly when backend is upgraded to v0.9.1
