## 🎯 Major Features

### Quran Module Refactoring (#112)
Complete architectural refactoring of the Quran module for improved separation of concerns and maintainability.

#### What Changed
- **Separated Components**: Split the single conditional `ayah` component into dedicated components:
  - `SurahAyahComponent` - For Surah viewing experience
  - `JuzAyahComponent` - For Juz/Para viewing experience
  - `AyahRedirectComponent` - Backward compatibility redirect handler

- **New Routing Structure**:
  - `/quran/surah-ayah` - Dedicated route for Surah viewing
  - `/quran/juz-ayah` - Dedicated route for Juz viewing
  - `/quran/ayah` - Redirect route (backward compatible)

- **Updated Navigation**:
  - Surah list navigates to `/quran/surah-ayah`
  - Juz list navigates to `/quran/juz-ayah`
  - Bookmark list intelligently routes based on bookmark type

#### Benefits
- ✅ **Better Code Organization**: Each component has a single, clear responsibility
- ✅ **Improved Maintainability**: Changes to Surah view don't affect Juz view
- ✅ **Easier Debugging**: No conditional logic to trace through
- ✅ **Future-Proof**: New features can be added without complexity
- ✅ **Backward Compatible**: Existing bookmarks and external links continue to work

#### Technical Details
- Eliminated 100+ lines of conditional logic
- Translation visible by default for Surah (unchanged)
- Translation hidden by default for Juz (unchanged)
- All functionality preserved: bookmarks, reading streaks, scroll-to-ayah, etc.
- 12 files changed: 765 additions, 8 deletions

## 🐛 Bug Fixes

### iOS PWA Theme Synchronization (v3.0.1 - v3.0.10)
Fixed multiple issues with theme color synchronization on iOS Progressive Web App.

**Issues Resolved:**
- Status bar not updating with theme changes
- Flash of incorrect theme color on app launch (FOUC)
- Theme not applying to mobile notch/status bar area

**Solutions Implemented:**
- Set status bar to `black-translucent` for proper theme transparency
- Added `viewport-fit=cover` for full-screen iOS support
- Removed legacy `apple-mobile-web-app-status-bar-style` meta tag
- Implemented immediate theme application in `index.html`
- Added global body background style for seamless theme transitions
- Centralized theme logic in dedicated `applyTheme` method

**Impact:**
- Consistent theme experience across all iOS devices
- No more theme flashing on app startup
- Proper status bar color matching in dark/light modes

### Ayah Component Cleanup (v3.0.11)
Removed excessive console logging from `AyahComponent`.

**Changes:**
- Cleaned up debug console logs
- Improved production performance
- Reduced console noise

## 🚀 Migration Guide

### For Existing Users

**Bookmarks:**
- All existing bookmarks will continue to work
- Old `/quran/ayah` links automatically redirect to appropriate new routes
- No action required

**Reading Streaks:**
- Reading streak data preserved
- New streak tracking uses optimized service
- Improved performance without data loss

**Theme Preferences:**
- Theme preferences maintained
- iOS users will see improved theme synchronization
- No manual theme reselection needed

### For Developers

**Routing Updates:**
- Update any hardcoded `/quran/ayah` references to use:
  - `/quran/surah-ayah` for Surah contexts
  - `/quran/juz-ayah` for Juz contexts
- Redirect component handles backward compatibility

**Component Usage:**
- Use `SurahAyahComponent` instead of conditional `AyahComponent` for Surah views
- Use `JuzAyahComponent` instead of conditional `AyahComponent` for Juz views
- Both components share the `AyahCardComponent` for individual ayah rendering

**Service Integration:**
- `BookmarkService` automatically handles both Surah and Juz bookmarks
- `ReadStreakService` optimized - remove any custom `localStorage` caching
- `ThemeService` centralized - use `applyTheme()` method for theme changes
