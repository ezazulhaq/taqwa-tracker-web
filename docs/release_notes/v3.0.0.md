# Release Notes - v3.0.0 (2026-01-24)

We are excited to announce the release of **The Taqwa Tracker Web v3.0.0**! This version brings a major overhaul to the user experience with a new modular home page, enhanced service logic for prayer timings, and significant UI/UX polish across the application.

## 🚀 Key Highlights

### 🏠 Home Page Redesign
*   **Widget-Based Layout**: The home page now features dynamic widgets for quick access to essential information.
*   **Prayer Timings Widget**: A dedicated widget to view upcoming prayer times at a glance.
*   **Recommended Apps Widget**: Quickly navigate to suggested features and integrations.
*   **"All Apps" View**: A new centralized component to view and access all tools and applications within the platform.

### 🕋 Prayer & Salah Enhancements
*   **Hanafi Time Logic**: Updated the Salah service to accurately calculate Asr and Isha timings using the Hanafi school of thought.
*   **Rakat UI Refinement**: Improved the interface for viewing Rakat details, making it more intuitive and visually appealing.

## ✨ Improvements & UX Polish

*   **PDF Viewer Upgrade**: Moved zoom controls and page navigation to the top of the container for better accessibility during reading.
*   **PWA Experience**: Relocated the PWA installation popup to the top of the interface for higher visibility.
*   **Navigation & Menu**: Repositioned the menu header to the bottom to improve thumb-reachability on mobile devices.
*   **Chatbot Interface**: Adjusted padding for the chatbot input field for a cleaner look.
*   **Generic App Icons**: Introduced a standardized app icon component for consistent branding across all modules.

## 🛠 Technical Notes
*   **Codebase Modernization**: Continued migration towards signals and standalone components in line with Angular v20+ best practices.
*   **Unified Styling**: Integrated the new generic app icon component to streamline asset management.
