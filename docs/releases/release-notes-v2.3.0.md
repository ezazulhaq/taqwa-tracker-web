# Release Notes - Taqwa Tracker v2.3.0

**Date:** January 22, 2026

We are pleased to introduce **Taqwa Tracker v2.3.0**, featuring a highly requested utility to enhance your asset management experience.

## Highlights

### 🧮 Integrated Floating Calculator
We have added a dedicated **Floating Calculator Tool** specifically for the Zakat Calculator page. This tool is designed to help you quickly tally assets, calculate shares, or perform any arithmetic operations without needing to switch apps or leave the page.

- **One-Tap Access**: A stylish floating action button (FAB) at the bottom right provides instant access to the tool.
- **Premium Design**: Features a modern, theme-consistent interface with glassmorphism effects and smooth animations.
- **Optimized Performance**: Built from the ground up using Angular's latest Signal-based reactive state for a snappy and reliable experience.
- **Mobile Friendly**: Perfectly tailored for both desktop and mobile use cases.
